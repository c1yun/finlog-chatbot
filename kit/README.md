# FAQ 챗봇 키트

핀로그 금융 챗봇의 검색 엔진으로 **어떤 가게·학원·동아리의 FAQ 챗봇이든** 만드는 도구입니다.
자주 묻는 질문을 엑셀(CSV)로 정리하면 **HTML 파일 하나짜리 챗봇**이 만들어집니다.

| | |
|---|---|
| 운영비 | **0원** — 서버, AI API, 월 구독이 필요 없음(무료 정적 호스팅에 올리면 끝) |
| 정확성 | 답을 지어내지 않음 — 사람이 써 둔 답 중에서만 골라 보여 줌 |
| 개인정보 | 질문이 어디에도 전송되지 않음(브라우저 안에서만 검색) |
| 검색 | 조사·구어체 처리, 오타 교정 제안(자모 단위), 비슷한 질문 후보, 모르는 낱말이 섞이면 확신하지 않기 |
| 설치 | 링크 공유 · QR 코드 · 홈페이지에 코드 한 줄(떠 있는 버튼) |
| 접근성 | 스크린리더 알림, 키보드 조작, 모바일 화면·한글 입력기 대응 |

데모(모두 가상 업체): `dist/cafe` · `dist/pension` · `dist/academy` · `dist/club`

---

## 1. 코딩 없이 만들기 — `builder.html`

1. `kit/builder.html`을 브라우저로 엽니다(더블클릭).
2. **예시로 시작하기**에서 비슷한 업종을 불러오거나, 엑셀 표를 **5. 질문·답변** 칸에 붙여 넣습니다.
3. 오른쪽 미리보기와 **검색 테스트**에 손님처럼 질문해 보며 키워드를 다듬습니다.
4. **index.html 받기**, **widget.js 받기** → 두 파일을 한 폴더에 넣고 [Netlify Drop](https://app.netlify.com/drop)에 끌어다 놓으면 인터넷 주소가 생깁니다.

입력한 내용은 그 브라우저에만 저장됩니다. 다른 컴퓨터로 옮길 때는 **프로젝트 저장(.json)**을 쓰세요.

## 2. 명령줄로 만들기 — `build.js` (고객이 여러 명일 때)

Node 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
node kit/build.js                      # 예시 4개 → kit/dist/, builder.html 다시 만들기
node kit/build.js 고객/온기카페          # 고객/온기카페/config.json + faq.csv → kit/dist/온기카페/
node kit/build.js 고객/온기카페 --out 납품
```

결과 폴더에는 `index.html`(챗봇), `widget.js`(홈페이지 버튼), `설치안내.txt`(고객에게 보낼 설명)가 생깁니다.

---

## 3. 질문표(CSV) 쓰는 법

첫 줄(머리글)은 아래와 같습니다. 엑셀에서 **CSV UTF-8**로 저장하세요(EUC-KR 파일도 제작 도구가 알아서 읽습니다).

| 카테고리 | 질문 | 답변 | 키워드 | 링크 |
|---|---|---|---|---|
| 위치·주차 | 주차할 수 있나요? | 매장 뒤편에 4대 주차할 수 있어요. | 주차, 주차장, 차, 차 가지고, 주차비 | 길찾기=https://map.naver.com/... |

- **답변**: 줄을 바꾸면 그대로 줄바꿈되고, `**굵게**`, 인터넷 주소는 자동으로 링크가 됩니다.
- **키워드**: 검색 품질을 좌우합니다. 손님이 **실제로 칠 말**을 쉼표로 5~10개 넣으세요.
  줄임말(와파, 레테, 동방), 구어체(차 가지고, 몇시까지), 비슷한 말(학원비=수강료=원비)을 넣으세요.
  한 글자 낱말(숯, 술, 차)도 키워드로 넣으면 따로 떨어진 낱말로 쓰일 때 알아듣습니다.
- **링크**: `버튼 이름=주소`를 `;`나 줄바꿈으로 여러 개 넣을 수 있습니다. 주소는 `https://`, `tel:`, `sms:`, `mailto:`만 됩니다.
- 같은 질문이 두 번 나오거나 답변이 비어 있으면 제작 도구와 `build.js`가 몇 번째 줄인지 알려 줍니다.

## 4. 설정(`config.json`)

| 항목 | 설명 | 예 |
|---|---|---|
| `name` | 챗봇·가게 이름 | `"온기 커피 로스터스"` |
| `tagline` | 머리말 아래 한 줄 소개 | `"영업시간·메뉴·주차, 무엇이든 물어보세요"` |
| `avatar` / `avatarFile` | 이모지, 또는 같은 폴더의 로고 파일(png·jpg·webp·svg, 300KB 이하 권장) | `"☕"` / `"logo.png"` |
| `theme` | `primary`(메인), `accent`(버튼), `bg`(배경). 글자색은 대비 4.5:1 이상으로 자동 조정 | `{"primary":"#5b3a29"}` |
| `greeting` | 첫 인사 | |
| `placeholder` | 입력창 안내 | `"예: 주차 돼요?"` |
| `examples` | 첫 화면 예시 질문(2~3개) | `["오늘 몇 시까지 해요?"]` |
| `noMatch` | 답을 못 찾았을 때 문구 | |
| `contacts` | 문의 버튼 목록 | `[{"label":"📞 전화하기","url":"tel:051-000-0000"}]` |
| `footer` | 아래쪽 작은 글씨 | |
| `credit` | 제작자 표시(선택) | `{"label":"챗봇 제작 문의","url":"https://..."}` |
| `reportUrl` | 답하지 못한 질문 수집 주소(선택, 6장) | |
| `widgetLabel` | 홈페이지 버튼 옆 말풍선 | `"궁금한 건 챗봇에게!"` |

## 5. 홈페이지에 붙이기(떠 있는 버튼)

챗봇 폴더(index.html + widget.js)를 올린 뒤, 홈페이지의 `</body>` 바로 앞에 한 줄을 넣습니다.

```html
<script src="https://내-챗봇.netlify.app/widget.js" data-color="#5b3a29" data-label="궁금한 건 챗봇에게!" defer></script>
```

선택 속성: `data-bot`(챗봇 주소를 따로 지정), `data-position="left"`, `data-open="true"`(처음부터 열기).
아임웹·카페24·워드프레스처럼 HTML을 넣을 수 있는 곳이면 됩니다. 네이버 블로그·스마트스토어처럼 스크립트를 못 넣는 곳에는 **링크나 QR 코드**로 연결하세요.

## 6. 답하지 못한 질문 모으기(선택)

챗봇이 답하지 못한 질문만 구글 시트에 쌓아, 한 달에 한 번 답변을 보강하는 데 씁니다.

1. 구글 시트 → 확장 프로그램 → Apps Script에 아래 코드를 붙여 넣습니다.
   ```js
   function doPost(e) {
     var d = JSON.parse(e.postData.contents);
     SpreadsheetApp.getActiveSpreadsheet().getSheets()[0].appendRow([new Date(), d.bot, d.kind, d.q]);
     return ContentService.createTextOutput('ok');
   }
   ```
2. 배포 → 새 배포 → 웹 앱(실행: 나, 액세스: 모든 사용자) → 나온 주소를 `reportUrl`에 넣습니다.
3. 챗봇 아래쪽에 "답하지 못한 질문만 익명으로 모은다"는 안내가 자동으로 붙습니다. 전화번호·이메일처럼 보이는 부분은 `***`로 가려서 보냅니다.

## 7. 검색 방식

- 질문·키워드·답변과의 겹침, 키워드 정확 일치, 두 글자 조각 유사도를 더해 점수를 냅니다. 여러 질문에 두루 나오는 낱말은 덜 중요하게 봅니다.
- **45점 이상**이면 바로 답하고, **22~44점**이면 "혹시 이 중에 있나요?"로 후보를 보여 줍니다.
- 모르는 낱말은 자모 단위로 가장 가까운 키워드를 찾아 **"혹시 ‘주차’에 대해 물어보신 건가요?"**라고 되묻습니다. 틀린 교정이 엉뚱한 답이 되지 않도록 바로 답하지는 않습니다.
- 챗봇이 전혀 모르는 낱말이 섞이면(예: "화장실 어디예요") 확신을 낮춰 후보로 보여 줍니다.
- 인사, 감사, "상담원 연결" 같은 말에는 기본 대답과 문의 버튼으로 응답합니다.

## 8. 테스트

```bash
node kit/test/run.js            # CSV·안전·검색 품질(손님 질문 120여 개) 테스트
node kit/test/run.js --verbose  # 질문별 점수표
node kit/test/e2e.js            # 브라우저 테스트(Playwright가 있을 때만)
```

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `src/engine.js` | 검색 엔진(브라우저·Node 공용) |
| `src/ui.js`, `src/style.css`, `src/template.html` | 챗봇 화면 |
| `src/assemble.js` | CSV 해석, 설정 검사, HTML 조립(브라우저·Node 공용) |
| `src/widget.js` | 홈페이지용 떠 있는 버튼 |
| `src/builder.src.html` | 제작 도구 원본(`build.js`가 `builder.html`로 만듦) |
| `examples/` | 가상 업체 4곳의 예시 데이터 |
| `dist/` | 빌드 결과(바로 올릴 수 있는 챗봇) |
| `test/` | 테스트 |

> 예시 업체(온기 커피 로스터스, 숲속별빛 펜션, 바른수학학원, 밴드 동아리 울림)와 주소·전화번호는 모두 가상입니다.
