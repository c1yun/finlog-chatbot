## 1장 수신(예금·적금·시장성 수신·예금자보호·비과세)

### 1-1 수신상품 분류 ★경남 2024 "거치식 상품 아닌 것 / 적립식·거치식"

### 1-2 이자 계산 공식 카드
- 단리 = 원금 × r × t, 복리 = 원금 × (1+r)^n, 72의 법칙: 2배 연수 ≈ 72 ÷ 이율(%).
- 정기예금 세전이자 = 원금 × 연이율 × 개월/12.
- 정기적금 세전이자 = 월납입액 × 연이율 × n(n+1)/2 ÷ 12. n=12이면 계수 78/12 = 6.5 ([예금·적금 이자 가이드](https://oursupporter.com/guide/deposit-savings-guide)).
- 예: 월 10만·연 3%·12개월 → 100,000 × 0.03 × 6.5 = **19,500원**, 세후 16,497원 ([계산 예시](https://www.youngju.dev/blog/finance/2026-06-13-deposit-interest-calculation-engine)).
- 세후 = 세전 × 0.846(이자소득세 14% + 지방 1.4%) ([삼일PwC](https://www.pwc.com/kr/ko/insights/issue-brief/samilpwc_one-point-tax-11.pdf)).

### 1-3 예금계약의 법적 성질
- 예금 = 민법상 **소비임치**(은행이 소유권 취득·운용, 같은 금액 반환; 조문·약관 문구 확인 필요).
- 성립 시점: 현금 → 은행이 받아 **확인한 때**; 계좌이체 → **원장 기록 때**; 수표·어음 → 부도반환시한 경과·결제 확인 때 ([예금거래기본약관 양식](https://lawinsider.com/ko/contracts/lVgDOINMdKn)).
- 예금채권 양도·질권은 은행 승낙 필요, 외화예금은 불가 ([하나은행 약관](https://image.kebhana.com/cont/download/documents/provide/c000020160331_20170818.pdf)). 은행은 대출채권과 예금을 **상계** 가능, 예보 보험금 지급 시에도 대출 먼저 차감 ([예보 보호한도](https://www.kdic.or.kr/sp/dpstrprot/ProtSystProtLmts/selectScrn.do)).

## 5장 채권·주식지표·파생·VaR·NPV ★부산 2022 "NPV·현가·듀레이션·파생", 2023 "옵션·수정듀레이션", 2020 "PER·PBR·전환사채", 경남 2024 "VaR·ROA·활동성비율", 2025 "콜 매수·매도"

### 5-1 채권
| 개념 | 정의·공식 |
|---|---|
| 채권가격 | P = Σ C/(1+y)^t + F/(1+y)^n. **금리↑ → 가격↓**(역관계) |
| 만기수익률(YTM) | 현금흐름 현재가치 = 시장가격이 되게 하는 할인율(채권의 IRR). 표면금리 < YTM이면 할인채(액면 이하) |
| 맥컬레이 듀레이션 | 현금흐름 현재가치 가중 **평균 회수기간(년)**. 무이표채 듀레이션 = 만기, 이표채 < 만기 |
| 수정듀레이션 | D_mod = D_Mac ÷ (1+y). **ΔP/P ≈ −D_mod × Δy** (D_mod 4, 금리 +1%p → 가격 −4%) |
| 듀레이션 결정요인 | 만기↑ → D↑ / 표면금리↑ → D↓ / YTM↑ → D↓ / 이자지급 빈도↑ → D↓ |
| 볼록성 | ΔP/P ≈ −D_mod·Δy + ½·C·(Δy)². 금리 하락 시 더 오르고 상승 시 덜 떨어짐(투자자 유리) |
| 신용등급 | 투자등급 **AAA~BBB−**, 투기등급 **BB+ 이하**. 단기등급 A1~D |
| 신용스프레드 | 회사채 − 국고채. 경기 악화 시 확대. 2026 3Q AA− 3년 4.39~4.79% vs 국고 3년 3.67~4.12% ([딜사이트](https://dealsite.co.kr/articles/170226)) |
| 전환사채(CB) | 주식 전환권 부여 사채(저금리). BW는 사채 유지 + 신주인수권. 할인채 = CD·전단채, 통안채 = 한은 발행 |

계산 예: 수정듀레이션 5, 금리 0.5%p 하락 → 가격 약 **+2.5%**. 듀레이션 개념 출처: [IBK투자증권 자산배분전략](https://m.ibks.com/iko/IKO01/download.do?seq=8342&gubun=MONT&menuCode=IKO010101&attatchCd=ATTATCH1).

### 5-2 주식·재무 지표
| 지표 | 공식 | 해석·함정 |
|---|---|---|
| **PER** | 주가 ÷ EPS | 낮을수록 저평가(적자기업 산출 불가), 성장주 高PER |
| **PBR** | 주가 ÷ BPS | **1 미만 = 청산가치 이하**. PBR = PER × ROE |
| **ROE** | 순이익 ÷ 자기자본 | 주주 관점 수익성 |
| **ROA** | 순이익 ÷ 총자산 | 은행 수익성 대표(ROA·ROE·NIM) |

| 안정성 | 유동비율 = 유동자산 ÷ 유동부채, 부채비율 = 부채 ÷ 자기자본, 이자보상배율 = 영업이익 ÷ 이자비용(1 미만 위험) | 활동성과 구분 |
| 재무제표 | 재무상태표·손익계산서·자본변동표·현금흐름표·주석 | **정산표는 재무제표 아님** ★경남 2024 |

### 5-3 NPV·IRR·현가 ★부산 2022
- PV = FV ÷ (1+r)^n. 연금현가, 영구연금 PV = C ÷ r.
- **NPV** = Σ CF_t/(1+r)^t − 투자액. **NPV > 0 채택**, 할인율 = WACC.
- **IRR** = NPV가 0인 할인율, **IRR > 자본비용이면 채택**. 충돌 시 **NPV 우선**.

### 5-4 파생상품·VaR
| 개념 | 핵심 |
|---|---|
| 선물 vs 선도 | 선물 = 거래소 표준화·청산소 상대방·증거금·**일일정산** / 선도 = 장외·만기 일괄정산·신용위험 |
| 콜 매수 / 매도 | max(S−K,0) − C: **최대손실 C·이익 무한** / 매도는 최대이익 C·손실 무한 |
| 풋 매수 / 매도 | max(K−S,0) − P: 최대손실 P·**최대이익 K − P** / 매도는 거울상 |
| 프리미엄 | 내재가치 + 시간가치(ATM 최대, 만기 접근 시 0). 변동성↑ 콜·풋 모두↑, 금리↑ 콜↑풋↓, 배당↑ 콜↓풋↑ |
| 풋-콜 패리티 | C + K·e^(−rT) = P + S |
| 스왑 | **IRS** 동일통화 고정↔변동 이자, 원금 미교환 / **CRS** 원금·이자 교환 |
| 동기 | 헤지(반대 포지션) / 투기 / 차익거래(현물-선물 괴리) |
| **VaR** | **일정 신뢰수준·보유기간**의 **최대 예상손실**. 포지션 × z × σ × √t (99% z 2.33, 95% 1.65). 예: 100억·일 σ 1%·99%·10일 → 100 × 2.33 × 0.01 × √10 ≈ **7.37억** |

## 8장 보험 ★부산 2022·2023 "보험", 경남 2024 "보험법·보험소비자 주의사항"

### 8-1 원리·분류·겸영
원리: **대수의 법칙**(표본↑ → 사고확률 수렴) / **수지상등**(단체 수입보험료 = 지급보험금) / **급부·반대급부 균등**(개별 보험료 = 확률 × 보험금).

| 구분 | 보험사고 | 지급 | 예 |
|---|---|---|---|
| 생명보험 | 생존·사망 | 정액 | 종신·정기·연금·변액 |
| 손해보험 | 재산상 손해 | 실손(이득금지) | 화재·자동차·배상책임·보증 |
| 제3보험 | 상해·질병·간병 | 정액·실손 모두 | 실손의료보험 |

겸영: 생보·손보 겸영 금지(보험업법 §10), **제3보험은 양쪽 모두 영위**. 손보사 질병사망 담보 한도 (확인 필요).

### 8-2 보험료 구조·예정기초율·해지환급금
영업보험료 = 순보험료(위험보험료 + 저축보험료) + 부가보험료(신계약비·유지비·수금비).

예정기초율: **예정이율↑ → 보험료↓**(할인 커짐) / 예정위험률(사망률)↑ → 사망보험↑·**연금보험↓** / 예정사업비율↑ → 보험료↑.

- 해지환급금 = 책임준비금 − 해약공제(미상각 신계약비) → 초기 1~2년 환급금 매우 적음. 무·저해지환급형은 보험료 낮은 대신 환급금 없거나 적음.
- 보장성(환급금 ≤ 납입, 세액공제 연 100만·12%) vs 저축성(환급금 > 납입, 10년 유지 등 비과세 요건 숫자 확인 필요) vs 변액(특별계정 투자).
- **변액보험 예금자보호**: 주계약(특별계정 운용분) 비보호, **최저보증보험금·특약은 보호** ([ABL생명 변액연금 안내장](https://abllife.co.kr/cms/prdt/bcsrn/__icsFiles/afieldfile/2021/01/05/변액연금보험안내장.pdf)).
