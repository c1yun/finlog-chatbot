## Q1. 펀드(집합투자기구) 구조·분류·비용·기준가격

### Takeaway
펀드는 "운용(자산운용사)·보관(수탁회사)·판매(판매회사)·사무관리(일반사무관리회사)"가 분리된 실적배당 상품이며, 판매수수료(1회성, 상한 2%)와 판매보수(매년, 상한 1%)를 구분하는 A/C클래스 문제, 사모펀드 "100인/일반투자자 49인" 수치가 함정 포인트다.

### Cited Findings
- 판매수수료·판매보수는 운용사와 판매사가 협의해 정하며 **자본시장법상 상한은 판매수수료 2%, 판매보수 1%** — [머니투데이 2021.3](https://www.mt.co.kr/stock/2021/03/22/2021032109113160262) [2차]
- 금감원 설명: **A클래스는 가입 시 1% 안팎의 선취수수료를 내지만 연간 판매보수가 낮아 장기투자용, C클래스는 선취수수료 없이 판매보수가 높아 단기투자용**; 대다수 펀드의 환매수수료는 가입 후 1~3개월 내 환매 시 부과되나 10년인 펀드도 있음 — [뉴스토마토(금감원 인용)](https://newstomato.com/ReadNews.aspx?no=776120) [2차]
- 금감원 2026.9 발표: 목표전환형 펀드 투자자의 71.8%가 A클래스를 택했지만 목표 달성 기간이 평균 57일로 짧아 수수료 구조와 투자기간을 함께 따져야 함 — [SBS Biz](https://biz.sbs.co.kr/amp/article/20000333611) [2차]
- 재간접펀드(FoF)는 투자대상 펀드의 비용이 더해지므로 **합성 총보수**로 비교 — [데일리안(금감원 안내)](https://m.dailian.co.kr/news/view/659258) [2차]
- 2021.10.21 시행 자본시장법 개정: 사모펀드 투자자 수 상한 **49인→100인**, 단 **일반투자자는 49인 이하 유지**; 운용목적 기준(전문투자형·경영참여형)→투자자 기준(**일반 사모펀드 / 기관전용 사모펀드**)으로 개편; 일반 사모펀드의 일반투자자는 3억원 이상 투자하는 적격투자자·전문투자자 — [뉴시스 2021.6.22](https://www.newsis.com/view/NISX20210622_0001485594); [데일리안](https://www.dailian.co.kr/news/view/1004055/) [2차]
- 예금자보호: 은행·증권사의 **금융투자상품(수익증권, MMF 등)은 비보호** — [예금보험공사 보호대상 금융상품 개요](https://www.kdic.or.kr/sp/dpstrprot/selectProtSystProtTrgtPrdctSumr.do) [1차]

## Q2. ETF vs ETN, ELS·DLS vs ELB·DLB vs ELD vs ELF/ELT — 원금보장·발행기관·예금자보호 비교

### Takeaway
"**ELD만 은행 예금이라 예금자보호 O**, ELB·DLB는 원금지급형이지만 증권사 신용에 의존해 **비보호**, ELS·DLS·ELF·ELT는 원금 비보장·비보호"가 핵심 판별표이며, ETN은 증권사가 발행한 파생결합증권이라 **발행사 신용위험·만기**가 있다는 점이 ETF와의 차이다.

### Cited Findings
- 예보 비보호 목록(증권사): **랩어카운트, ELS, ELB, ELW, 증권사 CMA, 증권사 발행채권, 종투사 발행어음, IMA, RP, MMF·수익증권** — [예금보험공사](https://www.kdic.or.kr/sp/dpstrprot/selectProtSystProtTrgtPrdctSumr.do) [1차]
- "원금보장형은 지난해 10월부터 각각 ELB와 DLB로 분류… '증권'이 '채권'으로 바뀐 셈". 금감원: **주가연계 파생결합사채(ELB)는 예금자보호 대상이 아니며 발행 증권사가 파산하면 수익 조건을 달성해도 원금·수익을 돌려받지 못할 위험** — [비즈워치 2014.1](https://news.bizwatch.co.kr/article/market/2014/01/22/0006); [뉴스토마토](https://newstomato.com/ReadNews.aspx?no=554870) [2차]
- ELD(주가지수연동예금)는 **은행이 발행하는 예금**으로 원금 보장·예금자보호법 적용, 단 주가 하락 시 이자가 0원이 될 수 있음; ELF는 자산운용사 펀드로 비보호 — [한국경제 2015](https://www.hankyung.com/amp/2015022715481) [2차]
- ELS/DLS는 파생결합증권(증권사 발행), 안정성 근거는 발행사 신용 — [한국투자증권 ELS/DLS 정의](https://securities.koreainvestment.com/mobile/item/_view/MMO50490.jsp); [삼성증권](https://www.samsungpop.com/ux/kor/customer/guide/workproductguide/elsDlsDeal.do) [2차]
- ETN은 "주식·ETF 등과 거래방법은 유사하나 상품의 성격 및 위험의 종류 등이 상이한 **파생결합증권**"; **괴리율**=시장가격과 실시간 지표가치(ETN) 또는 순자산가치 NAV(ETF)의 차이 비율; ETN 괴리율 초과 공시 기준은 국내기초 1%·해외기초 2%, 관리의무 비율 2배(국내 6%·해외 12%) 이상 시 적출 — [KRX KIND 공시 2026.2](https://kind.krx.co.kr/external/2026/02/03/000180/20260203000214/68648.htm); [KIND 2022.5](https://kind.krx.co.kr/external/2022/05/02/000026/20220502000034/68319.htm) [1차]
- ETN은 **만기 1년 이상 20년 이내**, 만기 시 자동 상환(매도)될 수 있어 매수 전 만기 확인; ETN 종목명 맨 앞에 발행 증권사명; 레버리지 ETF/ETN 거래는 금투협 사전교육 이수 필요 — [카카오페이증권 안내](https://kakaopaysec.com/downloadFile.do?id=10873); [aboda 블로그](https://aboda.kr/?p=24237) [2차]

### 교과 표준 정의 [교과]
- ELS 구조 용어: **낙인(Knock-In)**=만기까지 한 번이라도 기초자산이 낙인배리어(예: 최초가의 50%) 아래로 떨어지면 원금손실 조건 발동 / **녹아웃(Knock-Out)**=기초자산이 일정 수준 이상 상승 시 수익 확정·조기 종료 / **스텝다운**=6개월마다 조기상환 평가, 조기상환 조건(예 90-90-85-85-80-75%)이 점차 낮아지는 구조 / DLS=기초자산이 금리·환율·원자재·신용.
- ETF: 추적오차(tracking error)=ETF의 NAV 수익률과 기초지수 수익률의 차이(운용의 문제) ↔ 괴리율=시장가격과 NAV의 차이(수급·유동성의 문제). ETN은 발행사가 지수수익률을 "약속"하므로 운용 추적오차는 이론상 0, 괴리율만 발생.

### 예상 함정/OX
1. "ELB는 원금보장형이니 예금자보호 O" ✗ → 비보호(증권사 신용).
2. "ETN은 펀드다" ✗ → 증권사 발행 **파생결합증권(채권형 증권)**, 만기 있음.
3. "ETF 괴리율 = 추적오차" ✗ → 다른 개념.
4. "H지수 ELS 배상은 일괄 100%" ✗ → 기본 20~40%에 가감.

## Q5. 채권: 가격-금리, YTM, 듀레이션·볼록성, 신용등급, 종류 ★복기 "듀레이션"(부산 2022, 2023 수정듀레이션)

### Takeaway
채권가격은 금리와 역(−)의 관계이며, **수정듀레이션 D_mod = 맥컬레이 D ÷ (1+y)**, **ΔP/P ≈ −D_mod × Δy**가 계산문제의 핵심. 만기↑·표면금리↓·YTM↓이면 듀레이션↑(금리민감도↑), 볼록성은 듀레이션 근사의 2차 보정(항상 투자자에 유리).

### Cited Findings
- 듀레이션은 금리 변동에 대한 채권(자산) 가격 민감도 개념 — [IBK투자증권 자산배분전략 2025.12](https://m.ibks.com/iko/IKO01/download.do?seq=8342&gubun=MONT&menuCode=IKO010101&attatchCd=ATTATCH1) [2차] (내부 노트 06 §92 재인용)
- 내부 노트 06 §110: "채권가격–금리 역관계; 듀레이션(현금흐름 가중평균 회수기간=금리민감도; 만기↑·표면금리↓·YTM↑이면 듀레이션↓); 수정듀레이션 ΔP/P ≈ −D×Δy; 볼록성" — 내부 노트 `06_합격전략_과목콘텐츠_타행비교.md` [교과]

### 교과 표준 정의 [교과]
| 개념 | 정의·공식 |
|---|---|
| 채권가격 | P = Σ C/(1+y)^t + F/(1+y)^n. **금리↑ → 가격↓**(역관계), 금리 하락 시 가격 상승폭 > 금리 상승 시 하락폭(볼록성) |
| 만기수익률(YTM) | 채권을 만기까지 보유할 때 현금흐름의 현재가치=시장가격이 되게 하는 할인율(=채권의 IRR). 표면금리 < YTM이면 **할인채(액면 이하)**, > 이면 할증 |
| 맥컬레이 듀레이션 | 현금흐름 현재가치로 가중한 **평균 회수기간(년)**. **무이표채(할인채) 듀레이션 = 만기**, 이표채 듀레이션 < 만기 |
| 수정듀레이션 | D_mod = D_Mac / (1+y). **가격변동률 ≈ −D_mod × Δy** (예: D_mod 4년, 금리 1%p 상승 → 가격 약 4% 하락) ★계산 |
| 듀레이션 결정요인 | 만기↑ → D↑ / 표면금리↑ → D↓ / YTM↑ → D↓ / 이자지급 빈도↑ → D↓ |
| 볼록성(Convexity) | 가격-수익률 곡선의 곡률; ΔP/P ≈ −D_mod·Δy + ½·C·(Δy)². 볼록성이 클수록 금리 하락 시 더 오르고 상승 시 덜 떨어짐 |
| 신용등급 | 투자등급 **AAA~BBB−**, 투기등급 **BB+ 이하**, D=부도. 국내 3사(한국신용평가·NICE·한국기업평가). CP·전단채는 A1~D(단기등급) |
| 종류(발행주체) | 국고채(정부, 3·5·10·30·50년) / 통안채(한국은행, 유동성 조절) / 지방채 / 특수채(공사) / 금융채(은행채·카드채) / 회사채 |
| 이자지급 방식 | **이표채**(정기 이자) / **할인채**(선이자 차감 발행, 만기 액면: CD·전단채·통안채 일부) / **복리채**(이자 재투자 후 만기 일시: 국민주택채권) |
| 신용스프레드 | 회사채 수익률 − 국고채 수익률(동일 만기). 경기 악화·신용위험↑ 시 확대 |

### 예상 함정/OX
1. "금리가 오르면 채권가격도 오른다" ✗.

### 교과 표준 공식표 [교과]
| 지표 | 공식 | 해석·함정 |
|---|---|---|
| EPS | 당기순이익 ÷ 발행주식수 | 주당 이익 |
| BPS | 자기자본(순자산) ÷ 발행주식수 | 주당 장부가 |
| **PER** | 주가 ÷ EPS (= 시가총액 ÷ 순이익) | 낮을수록 저평가(단, 적자기업은 산출 불가), 성장주 高PER |

| **ROE** | 당기순이익 ÷ 자기자본 | 주주 관점 수익성; PBR = PER × ROE |
| **ROA** | 당기순이익 ÷ 총자산 | 은행 수익성 대표지표(ROA·ROE·NIM) |

## Q7. 파생상품: 선물·옵션·스왑·헤지/투기/차익거래·VaR ★복기 "파생·VaR"(부산 2022·2023, 경남 2024 VaR·2025 콜 매수/매도)

### Takeaway
옵션 만기 손익은 **콜 매수 = max(S−K,0)−프리미엄(최대손실=프리미엄, 이익 무한)**, **풋 매수 = max(K−S,0)−프리미엄(최대이익=K−프리미엄)**, 매도는 그 거울상(이익=프리미엄 한정, 손실 무한/K−프리미엄). VaR은 "일정 신뢰수준·보유기간에서 발생 가능한 **최대손실액**"으로 정의.

### Cited Findings
- 2023 하(온라인) 복기 "콜·풋옵션", 경남 2024 "VaR 구하기", 경남 2025 "콜 매수·매도" — 내부 노트 08 §2-10 (https://www.topbanker-ai.co.kr/guide/knb-trend.html ) [2차]
- 레버리지 ETF/ETN 매매 시 금투협 사전교육 의무 — [카카오페이증권](https://kakaopaysec.com/downloadFile.do?id=10873) [2차]

### 교과 표준 정의 [교과]
| 개념 | 핵심 |
|---|---|
| 선물(Futures) | 거래소 표준화 계약, **청산소가 거래상대방**(신용위험 제거), **증거금**(개시·유지증거금, 유지 미달 시 마진콜→개시증거금까지 추가납입), **일일정산**(mark-to-market) ↔ 선도(Forward)는 장외·맞춤·만기 일괄정산·신용위험 有 |
| 베이시스 | 선물가격 − 현물가격. 이론선물가 = 현물 × (1 + (r − d) × t); 정상시장(콘탱고, 선물>현물)·역조시장(백워데이션); 만기일 베이시스 → 0(수렴) |
| 콜옵션 매수 | 손익 = max(S_T − K, 0) − C. 손익분기 S = K + C. **최대손실 = 프리미엄 C, 최대이익 무한** |
| 콜옵션 매도 | 손익 = C − max(S_T − K, 0). **최대이익 = C, 최대손실 무한** |
| 풋옵션 매수 | 손익 = max(K − S_T, 0) − P. 손익분기 S = K − P. **최대손실 = P, 최대이익 = K − P**(주가 0일 때) |
| 풋옵션 매도 | 손익 = P − max(K − S_T, 0). **최대이익 = P, 최대손실 = K − P** |
| 내재가치·시간가치 | 옵션프리미엄 = 내재가치 + 시간가치. 콜 내재가치 = max(S−K,0), 풋 = max(K−S,0). ITM(내가격)·ATM(등가격)·OTM(외가격). 시간가치는 ATM에서 최대, 만기 접근 시 0으로 소멸(세타) |
| 옵션가격 결정요인 | 기초자산가격↑: 콜↑풋↓ / 행사가↑: 콜↓풋↑ / 변동성↑: 콜·풋 모두↑ / 잔존만기↑: 모두↑(美式) / 금리↑: 콜↑풋↓ / 배당↑: 콜↓풋↑ |
| 풋-콜 패리티 | C + K·e^(−rT) = P + S |
| 스왑 | **금리스왑(IRS)**=동일통화 고정↔변동 이자 교환, 원금 교환 없음 / **통화스왑(CRS)**=서로 다른 통화의 원금·이자 교환(만기 원금 재교환) / 한미 통화스왑은 중앙은행 간 |
| 거래 동기 | **헤지**(위험 회피: 보유현물 반대 포지션, 매도헤지/매수헤지) / **투기**(방향성 베팅) / **차익거래**(무위험: 현물-선물 가격괴리 이용, 베이시스가 이론치 벗어날 때) |
| **VaR** | "정상시장에서 **일정 신뢰수준(95%·99%)·일정 보유기간** 동안 발생할 수 있는 **최대 예상손실액**". 계산: VaR = 포지션가치 × z × σ × √t (99%: z=2.33, 95%: z=1.65). 예: 100억, 일 σ 1%, 99%, 10일 → 100억×2.33×1%×√10 ≈ 7.37억 ★경남 2024 "VaR 구하기" |
| 기타 위험 용어 | 델타(기초자산 변화 민감도)·감마·세타·베가; 바젤 시장리스크 측정에 VaR 사용 |

### 예상 함정/OX
1. "콜옵션 매도자의 최대손실은 프리미엄" ✗ → 매수자의 최대손실이 프리미엄, 매도자는 무한.
2. "풋 매수의 최대이익은 무한" ✗ → K − P.

4. "금리스왑은 원금을 교환" ✗ → 이자만, 통화스왑이 원금 교환.
5. "VaR 신뢰수준이 높을수록 VaR 금액이 작다" ✗ → 커진다.

## Q11. 금융소비자보호법(2021.3.25 시행) — 6대 판매원칙·소비자 권리·과징금·상품/판매업자 분류

### Takeaway
금소법은 **금융상품 4유형(예금성·대출성·투자성·보장성)·판매업자 3유형(직접판매·판매대리중개·자문)**에 **6대 판매원칙**을 공통 적용하고, 소비자에게 **청약철회권(보험 15일/대출 14일/투자성 7일)·위법계약해지권(안 날 1년·계약일 5년)·자료열람요구권**을 부여하며, **징벌적 과징금은 수입의 50%까지(적합성·적정성 제외 4개 원칙)**, 과태료 상한 1억 원이다. 적정성원칙은 **소비자가 먼저 청약**하는 파생·고난도 상품 등에 적용된다는 점이 적합성과의 차이.

### Cited Findings
- 법제처 생활법령 "금융상품 6대 판매원칙": 적합성원칙(§17)=권유 전 일반/전문금융소비자 확인 후 부적합 계약 권유 금지; **적정성원칙(§18)=소비자가 스스로 계약을 원할 때 재산상황 등에 비추어 적정하지 않으면 고지**; 판매자의 권유 없이 소비자가 원하는 경우 적합성원칙 미적용 — [법제처 easylaw](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1771&ccfNo=1&cciNo=1&cnpClsNo=2) [1차]
- 금융위 10問10答(2021.3.25): 6대 판매원칙 위반 **과태료 상한 1억 원**; **징벌적 과징금은 적합성·적정성 제외 4개 규제 위반에 한해 수입 등의 50% 상한**; 위법계약해지 시 판매자는 수수료·위약금 등 해지비용 요구 불가, 효과는 장래를 향해 발생; 내부통제기준·핵심설명서는 2021.9.25 시행 — [금융위원회 보도참고](https://www.fsc.go.kr/no010101/75613) [1차]
- 금융위: 투자성·보장성은 손실감수능력, 대출성은 상환능력으로 적합성 평가, **예금성 상품은 적합성원칙 적용 대상 아님**; 적합성·적정성·설명의무·청약철회권·소액분쟁조정 이탈금지는 **일반금융소비자에 한해 적용** — [금융위원회 정책자료](https://fsc.go.kr/po020201/75644) [1차]
- 청약철회: **대출은 계약서류 제공일·계약체결일·대출금 지급일 중 늦은 날부터 14일**(이용기간 이자만 납부); **보험은 보험증권 수령일부터 15일 또는 청약일부터 30일 중 먼저 도래하는 기간**; 6대 원칙 위반 시 5년 이내 대통령령으로 정하는 기간 내 계약 해지 가능 — [토스피드](https://toss.im/tossfeed/article/protection-law-of-finance-consumer); [한국교육신문](https://www.hangyo.com/news/article.html?no=94839) [2차]
- 징벌적 과징금 "수입 또는 이에 준하는 금액의 50% 이내" — [카드고릴라](https://www.card-gorilla.com/contents/detail/1746) [2차]
- 금소법 조문 사이드정보(§17 적합성원칙) — [law.go.kr 금융소비자 보호에 관한 법률](https://www.law.go.kr/LSW//lsSideInfoP.do?lsiSeq=277247&joNo=0017&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR) [1차, 본문 미수신]
